# Müll Kalender

## Zweck

Home-Assistant-Custom-Integration für den UBZ-Abfallkalender in Zweibrücken.
Die Integration liest eine ICS/iCal-URL und erzeugt Sensoren für die nächsten
Abholtermine.

## Projektstruktur

- Integration: `custom_components\zweibruecken_waste`
- Tests: `tests`

## Arbeitsregeln

Bestehende Entity IDs, Home-Assistant-Verträge und lokale Nutzeränderungen
erhalten. Vor Änderungen `AGENTS.md` und `PROJECT-STATE.md` lesen.

## Aktueller Hinweis

Im Arbeitsbaum sind lokale Löschungen markiert. Diese wurden bei der Migration
nicht verändert oder wiederhergestellt.
